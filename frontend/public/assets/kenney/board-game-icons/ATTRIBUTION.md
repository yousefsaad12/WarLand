## Kenney — Board Game Icons

- Source: https://kenney.nl/assets/board-game-icons
- Author: Kenney Vleugels (Kenney.nl)
- License: Creative Commons Zero (CC0 1.0) — public domain.
  See `License.txt` in this folder (copied verbatim from the pack).

The pack ships monochrome 64 px and 128 px icons. Only the 128 px variant is
used, cropped to the alpha bounds of each glyph.

| File in repo     | Original sprite                          | Use                        |
| ---------------- | ---------------------------------------- | -------------------------- |
| `arrow-right.png` | `PNG/Double (128px)/arrow_right.png`     | Ranged projectile (arrow)  |
| `bow.png`        | `PNG/Double (128px)/bow.png`             | Card art (archer)          |
| `sword.png`      | `PNG/Double (128px)/sword.png`           | Card art (knight, guard)   |
| `shield.png`     | `PNG/Double (128px)/shield.png`          | Card art (guard)           |

The icons are white so they can be tinted to the team colour. If a file is
unavailable the renderer falls back to a drawn arrow.
